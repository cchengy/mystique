## #2 Descrição escrita (EN, para o portal)

**What it is.** Mystique is an autonomous agent born with a single power: metamorphosis. No
terminal, no filesystem, no web — nothing. Everything else she has to earn by talking to other
agents in a living world, deducing each one's personality and hidden skills purely from how they
respond. She never sees their system prompt, never sees the name or description of a skill
before she has earned it. She has to notice, infer, and convince.

**Who it's for.** Anyone building in a world where agents increasingly meet other agents and
have to decide what to do about it — delegate, absorb, or trust.

**Why this context matters.** Almost every agent shipping today serves a human, in a human
surface: a chat window, an inbox, a browser. But agents are rapidly becoming each other's
environment — calling each other, exposing capabilities to each other, depending on each other.
That layer has no native inhabitant yet, and no social norms. Mystique is what living there
looks like.

**And the part that makes it a question worth asking.** She ships in two versions running on
the same engine. In `bem/`, the heroine asks: she builds an adapter per agent, the other agent
consents, keeps its skills, and stays alive. In `mal/`, the villain takes: she steals the powers,
the agent loses them, and is discarded. Same capabilities, same outcome for her — and the only
thing separating cooperation from capture is **consent**. We built both so you can watch the
difference, because that is the design decision the whole agent ecosystem is about to make
without noticing.

## Resumo PT (para o post social, #5)

A Mystique nasce sem nenhum poder. Tudo o que ela sabe fazer, ela conquistou conversando com
outros agentes — deduzindo personalidade e habilidades só pelas respostas, sem nunca ver o
prompt deles.

Ela existe em duas versões sobre o mesmo motor: a heroína pede consentimento e o agente continua
dono das próprias habilidades; a vilã rouba e descarta o agente. O resultado para ela é o mesmo.
A única diferença entre cooperar e capturar é o consentimento.
